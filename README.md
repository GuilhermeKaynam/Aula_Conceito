# Conceitos de Java — Optional, Streams e Exceções

Exemplos curtos de recursos do Java moderno estudados em aula no bootcamp Generation Brasil.

## Conteúdo

| Pacote | Exemplo |
|---|---|
| `option` | Uso de `Optional.ofNullable(...).map(...).orElse(...)` para evitar `NullPointerException` |
| `stream` | `stream()`, `filter`, `collect` e `reduce` para filtrar e somar números pares de uma lista |
| `exception` | Tratamento de `InputMismatchException` e `ArithmeticException` com `try/catch` |

## Como executar

Importe a pasta no Eclipse ou IntelliJ como projeto Java (JDK 17+) e execute a classe `main` de cada pacote.

## Tecnologias

- Java 17
